# 🌐 Static Website Hosting with GitHub Pages

## 📌 Overview
This project demonstrates how to host a static website using **GitHub Pages**. The website is built with HTML and CSS and deployed directly from a GitHub repository.

## 🎯 Objective
Deploy a simple, publicly accessible website using GitHub Pages to understand the basics of static website hosting and Git-based deployment.

## 🛠️ Technologies Used
- **HTML5** — Website structure
- **CSS3** — Styling and layout
- **Git** — Version control
- **GitHub** — Source code repository
- **GitHub Pages** — Static website hosting

## ✨ Features
- Simple and responsive webpage
- Custom styling using CSS
- Publicly accessible website
- Hosting directly from a GitHub repository

## 🚀 Deployment Steps
1. Created an `index.html` file containing the website code.
2. Initialized a Git repository and committed the source code.
3. Pushed the repository to GitHub.
4. Navigated to **Settings → Pages**.
5. Selected the `main` branch and `/ (root)` directory as the deployment source.
6. Saved the configuration and waited for GitHub Pages to publish the website.
